# 界面字号可调

## 背景

界面文字偏小：正文 13px，卡片正文 12px，元信息与角标 10-11px，
约 240 处写死的像素字号散在 26 个文件里。用户既看不清，也没有调节入口；
字号写成 `text-[11px]` 这类绝对值，就算给了开关也调不动它们。

另外还有两处「字号不生效」的隐患：`.timecode` 等排版辅助类与工具类同层，
同层顺序压过了调用处写的字号；组件基类自带 `text-sm`，而 `cn()` 用的 tailwind-merge
不认得本项目自定义的字号类名，覆盖不了基类。

## 目标

1. 设置页提供「界面字号」下拉，直接选正文像素值 12-26px，选好立即生效。
2. 默认字号从 13px 提到 14px，其余字号按同一比例跟着变。
3. 界面文字统一走一套语义字号；承载文字的尺寸（栏宽、阅读区上限）也随字号缩放。
4. 让「调用处写了字号就一定生效」成立，不再出现被基类或辅助类压掉的情况。

## 非目标

- 不做按模块分别设置字号。
- 不改动颜色令牌与主题。
- 不引入字体族切换。

## 影响

- 设计令牌：`globals.css` 新增十级语义字号与根字号缩放开关；排版辅助类移入 components 层。
- 工具层：`lib/utils.ts` 把语义字号注册进 tailwind-merge，使调用处能覆盖组件基类。
- 组件原语：`Input` / `Textarea` 不再写死响应式字号。
- 前端：26 个文件的 242 处写死字号换成语义类；承载文字的尺寸改为 rem。
- 外观偏好：`theme-store` 扩展为 `appearance-store`，同时管理主题与字号，并写入首屏脚本。
